# Practical 1: Introduction to MLOps

## Output

MLOps applies software engineering and operations practices to the full machine-learning lifecycle: data, features, experiments, model validation, deployment, monitoring, and retraining.

| Software development | DevOps | MLOps |
| --- | --- | --- |
| Versioned application code and releases | Automates build, test, release, and infrastructure | Versions code, data, features, experiments, and models; validates and monitors model behavior |
| Output is deterministic for a fixed build and input | Production system is the deployed application | Results also depend on training data, feature logic, parameters, and model artifacts |

```mermaid
flowchart LR
  A[Collect data] --> B[Validate and transform]
  B --> C[Version features]
  C --> D[Train and track]
  D --> E[Evaluate and register]
  E --> F[Deploy and serve]
  F --> G[Monitor data and model]
  G --> H[Retrain when needed]
  H --> B
```

Key components: source control, data/version management, feature store, automated pipelines, experiment tracking, model registry, tests/CI, containerization, serving, and monitoring.

Production challenges include data and concept drift, training-serving skew, reproducibility, latency, privacy, explainability, model rollback, and artifact/storage costs. Tool survey for this repository: Git/GitHub Actions, DVC, Feast, MLflow, scikit-learn, FastAPI, and Docker.
