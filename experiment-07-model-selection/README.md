# Experiment 7 - Baseline Model and Hyperparameter Search

## Aim
Compare a baseline classifier with grid-search and randomized-search candidates using held-out evaluation.

## Requirements
- Python dependencies from the repository-root `requirements.txt`
- Deterministic synthetic dataset generated by the shared pipeline

## Procedure
1. Run `python -m mlops_practicals.run_pipeline` from the repository root.
2. Compare models using the recorded macro-F1 selection metric.
3. Review parameters and held-out metrics in `outputs/model_comparison.json`.

## Observed result
The pipeline compared logistic regression, a grid-search decision tree, and a randomized-search random forest. All achieved 1.0000 on the 60-row synthetic holdout; the caveat and complete values are in [`OUTPUT.txt`](./OUTPUT.txt).

## Viva questions
1. How do grid search and random search differ?
2. Why keep a held-out test set separate from cross-validation?
3. Why are these perfect synthetic scores not evidence of production quality?

## Concept summary
Hyperparameter search compares candidate configurations using a repeatable validation strategy.

## Outcome summary
The experiment records baseline/tuned comparison; the synthetic label construction limits interpretation of its scores.
