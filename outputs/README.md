# Generated Outputs

`run_summary.json` and `model_comparison.json` are generated by running `python -m mlops_practicals.run_pipeline`. `test-results.md` summarizes the latest successful local test run. These outputs intentionally contain summaries rather than names from the supplied student CSV. The pipeline's synthetic training CSV, feature files, and model artifact are local reproducible outputs; use DVC for storing/versioning them when the optional remote is configured.

Experiment-specific command logs are recorded in each `experiment-*/OUTPUT.txt`. Git/DVC remotes, Feast services, MLflow UI/model registry, GitHub Actions, and Docker image logs must be captured after those tools/services are configured; they are not represented as completed runs here.
